# Proofdesk

Inspired by John Miranda’s enterprise AI governance messaging and sales enablement experience. The fictional claim set demonstrates how a product marketer scopes, substantiates, and hands off buyer-facing copy.

Open `index.html` directly in a modern browser. No install, account, or backend is required.

Edit or add a claim, save it, and download a Markdown handoff. The built-in sample is fictional. The workspace lives in memory and resets on reload.


[Open the live demo](https://johnmir94.github.io/proofdesk/)
